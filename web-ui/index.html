How to use

Please input the following parameters.

Context (from the course handout). Data volume has grown sharply (e.g. health events, cheap storage, always-on networks). Useful analysis usually starts by extracting a subset of samples that is as fair and unbiased as possible—and as optimal as possible under clear rules. This project implements one such combinatorial formulation: pick n items from m, then build a minimum set of k-groups that satisfy the j / s / at least coverage rules.

This tool finds that minimum (exactly when the search space is small, otherwise with a time-bounded heuristic).

  • Set m, n, K, j, S and at least.
  • Choose Random n (system picks) or Input n (you type the numbers).
  • Click Execute to run. Results appear below.
  • Use Store to save the run; open the Data Base tab to Display or Delete.
