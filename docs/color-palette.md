## 主色调

### 背景色系
| 颜色 | 十六进制 | RGB | 用途 |
|------|---------|-----|------|
| 主背景 | `#0d1117` | rgb(13, 17, 23) | 页面背景、输入框背景、section 背景 |

| 标题栏背景 | `#21262d` | rgb(33, 38, 45) | 标题栏、按钮背景、hover 背景 |

## 阴影和透明度

### Box Shadow
- **窗口阴影**: `rgba(0, 0, 0, 0.4)`
- **按钮 Hover**: `rgba(88, 166, 255, 0.25)`
- **按钮 Active**: `rgba(88, 166, 255, 0.3)`
- **Section Hover**: `rgba(0, 0, 0, 0.3)`
- **输入框 Focus**: `rgba(88, 166, 255, 0.15)`

### 虚线效果
- **按钮点击反馈**: `rgba(88, 166, 255, 0.6)`

## 颜色使用原则

1. **主色调**: 蓝色 `#58a6ff` 用于强调、链接、交互元素
2. **背景层次**: 从深到浅 `#0d1117` → `#161b22` → `#21262d`
3. **文字层次**: 主文字 `#c9d1d9`，次要 `#8b949e`，占位符 `#6e7681`
4. **功能颜色**: 
   - 绿色 `#7ee787` - 成功/输出
   - 红色 `#f85149` - 错误/危险
   - 黄色 `#d29922` - 警告
   - 蓝色 `#58a6ff` / `#79c0ff` - 信息/提示
