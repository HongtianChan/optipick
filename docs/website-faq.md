# Website FAQ

## Is the hosted site permanent?
The Vercel URL is stable as long as the project stays active and within service limits.

## Is it free?
For coursework/demo traffic, the free tier is usually enough. Heavy traffic may require paid plans.

## Can I use a custom domain?
Yes. Add it in Vercel project settings after deployment.

## Is data backed up automatically?
- Local mode data is saved on your machine (`~/.optimal-samples-selector/db/`).
- Cloud records depend on Supabase configuration and retention strategy.
