# Development Journey

## Milestones

1. **Initial solver**
   - Built set-cover formulation and baseline search.
2. **Web UI integration**
   - Added interactive parameter input and result rendering.
3. **Local runtime path**
   - Added CLI server for offline/local solving.
4. **Persistence improvements**
   - Added local file DB and optional cloud persistence.
5. **Performance tuning**
   - Added coverage precompute, pruning, and post-pass reduction.

## Outcome
The project now supports both demo-friendly UI and script-friendly CLI with a shared algorithmic core.
