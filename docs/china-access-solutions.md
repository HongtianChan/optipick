# Mainland China Access Options

If the hosted Vercel site is unstable from mainland China, use one of these options:

1. **Local mode (recommended for class demos)**  
   Run `npm run local:web` and use `http://localhost:3000`.
2. **Mirror deployment**  
   Deploy the same repo to another region/provider and share that link.
3. **Network workaround**  
   Use a stable network route that can access Vercel reliably.

For guaranteed availability in class, always keep local mode as backup.
