# 使用示例：E.g. 5

## 示例参数

根据 Group Project 说明，E.g. 5 的参数：
- **m** = 45（总样本数）
- **n** = 8（从 m 中选的样本数）
- **k** = 6（组大小）
- **j** = 6
- **s** = 5
- **at least** = 1（默认值）

**预期结果**：最少 4 组

## 操作步骤

### 方式 1：随机模式（推荐，最简单）

1. **打开网站**
   - 访问：https://optipick-system.vercel.app

2. **输入参数**
   - 在 "Parameters" 区域输入：
     - m: `45`
     - n: `8`
     - k: `6`
     - j: `6`
     - s: `5`
     - at least: `1`（默认值，不用改）

3. **选择模式**
   - 选择 **"Random n"**（系统随机选 8 个数字）

4. **执行计算**
   - 点击 **"execute"** 按钮
   - 系统会：
     - 随机从 1-45 中选 8 个数字
     - 显示在 "Selected Samples" 区域（例如：1st # 5, 2nd # 12, ...）
     - 计算最优组
     - 在 "results" 区域显示结果

5. **查看结果**
   - "results" 区域会显示：
     - 使用的算法（backtrack 或 greedy）
     - 最少组数（应该是 4 组）
     - 具体的组列表（例如：1. [1, 2, 3, 4, 5, 6], 2. [2, 3, 4, 5, 6, 7], ...）

6. **保存结果**（可选）
   - 点击 **"store"** 按钮
   - 结果会保存到数据库
   - 文件名格式：`45-8-6-6-5-1-4`（m-n-k-j-s-运行次数-结果数量）

### 方式 2：手动输入模式

如果你想指定具体的 8 个数字：

1. **输入参数**（同上）
   - m: `45`, n: `8`, k: `6`, j: `6`, s: `5`

2. **选择模式**
   - 选择 **"Input n"**
   - 会显示 "Manual Input" 区域，有 8 个输入框（因为 n=8）

3. **手动输入数字**
   - 在输入框中输入 8 个数字（范围 1-45）
   - 例如：`5, 12, 23, 31, 38, 42, 15, 28`
   - 输入的数字会自动显示在 "Selected Samples" 区域

4. **执行计算**
   - 点击 **"execute"**
   - 查看结果

5. **保存结果**（可选）
   - 点击 **"store"**

## 查看已保存的结果

1. **切换到数据库界面**
   - 点击顶部的 **"database"** 标签

2. **查看文件列表**
   - 左侧显示所有保存的文件
   - 例如：`45-8-6-6-5-1-4`

3. **显示文件内容**
   - 点击文件列表中的某个文件（会高亮显示）
   - 点击 **"Display"** 按钮
   - 右侧会显示该文件的详细内容

4. **删除文件**（可选）
   - 选中文件后，点击 **"Delete"** 按钮

5. **返回主界面**
   - 点击 **"back"** 按钮

## 预期结果

根据 E.g. 5 的要求：
- **最少组数**：4 组
- **条件**：至少一组包含至少一个 s=5 样本组合（从所有 j=6 样本组合中）

实际结果可能因为随机选择的 n 个数字不同而略有差异，但组数应该接近 4。

## 注意事项

1. **参数范围**：
   - m: 45-54
   - n: 7-25
   - k: 4-7
   - j: s ≤ j ≤ k
   - s: 3-7

2. **随机模式**：每次点击 execute 会随机选择不同的 n 个数字，结果可能不同

3. **手动输入**：确保输入的 n 个数字在 1-m 范围内，且不重复

4. **结果验证**：如果结果组数远大于预期，可能是参数设置有问题，检查 j 和 s 的关系
