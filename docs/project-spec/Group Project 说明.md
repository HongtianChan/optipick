**最优样本选择系统**。从大数据里选子集，要求公平、无偏、最优。

## 问题定义

### 参数说明

- **m**: 总样本数，范围 `45 ≤ m ≤ 54`
- **n**: 从 m 中随机选的样本数，范围 `7 ≤ n ≤ 25`
- **k**: 从 n 中选 k 个组成组，固定 `k = 6`（但实际范围是 `4 ≤ k ≤ 7`）
- **j**: 从 n 个样本中选 j 个，范围 `s ≤ j ≤ k`
- **s**: 从 j 个样本中选 s 个，范围 `3 ≤ s ≤ 7`

### 核心条件

**Condition 1**: 选出的 k=6 样本组中，至少有一组满足：
- 这组包含来自某个 j 样本组合的所有 s 样本组合

**具体规则**：
- 如果 `j=4`，则 `s=3` 或 `4`
- 如果 `j=5`，则 `s=3`、`4` 或 `5`
- 如果 `j=6`，则 `s=3`、`4`、`5` 或 `6`
- 如果 `j=7`，则 `s=3`、`4`、`5`、`6` 或 `7`

**重要理解**：
- 当 `j = s` 时：要求"所有"（ALL），即每个 j 组合的所有 s 组合都要被覆盖
- 当 `j ≠ s` 时：要求"至少一个"（at least ONE），即每个 j 组合至少有一个 s 组合被覆盖

### 目标

找**最少数量的 k=6 样本组**，满足上述条件。

## 计算公式

### 组合数公式

组合数 `nCk`（从 n 个中选 k 个的组合数）：

```
nCk = n! / (k! × (n-k)!)
```

其中 `n!` 是 n 的阶乘：`n! = n × (n-1) × (n-2) × ... × 2 × 1`

### 关键组合数

1. **mCn**: 从 m 个样本中选 n 个的组合数
   ```
   mCn = m! / (n! × (m-n)!)
   ```
   例如：`45C7 = 45! / (7! × 38!) = 45,379,620`

2. **nCk**: 从 n 个样本中选 k 个的组合数（所有可能的 k=6 组）
   ```
   nCk = n! / (k! × (n-k)!)
   ```
   例如：`n=7, k=6` → `7C6 = 7! / (6! × 1!) = 7`

3. **nCj**: 从 n 个样本中选 j 个的组合数
   ```
   nCj = n! / (j! × (n-j)!)
   ```
   例如：`n=8, j=5` → `8C5 = 8! / (5! × 3!) = 56`

4. **jCs**: 从 j 个样本中选 s 个的组合数
   ```
   jCs = j! / (s! × (j-s)!)
   ```
   例如：`j=5, s=5` → `5C5 = 1`（只有一种组合）

### 常用组合数速查

| n | k | nCk | 说明 |
|---|---|-----|------|
| 7 | 6 | 7 | E.g. 1 |
| 8 | 6 | 28 | E.g. 2, 3, 5, 6 |
| 8 | 5 | 56 | j=5 的情况 |
| 8 | 4 | 70 | j=4 的情况 |
| 9 | 6 | 84 | E.g. 4, 7 |
| 9 | 5 | 126 | j=5 的情况 |
| 9 | 4 | 126 | j=4 的情况 |
| 10 | 6 | 210 | E.g. 8 |
| 12 | 6 | 924 | E.g. 9 |

## 示例详解

### E.g. 1
- **参数**：`m=45`, `n=7` (A-G), `k=6`, `j=5`, `s=5`
- **结果**：最少 6 组
- **条件**：至少一组包含所有 5 样本组合（从所有 5 样本组合中）
- **计算**：
  - `7C6 = 7`（7 个可能的 k=6 组）
  - `7C5 = 21`（21 个可能的 j=5 组）
  - `5C5 = 1`（每个 j=5 组只有 1 个 s=5 组合）
  - 需要覆盖所有 21 个 j=5 组

### E.g. 2
- **参数**：`m=45`, `n=8` (A-H), `k=6`, `j=5`, `s=5`
- **结果**：最少 12 组
- **条件**：至少一组包含所有 5 样本组合（从所有 5 样本组合中）
- **计算**：
  - `8C6 = 28`（28 个可能的 k=6 组）
  - `8C5 = 56`（56 个可能的 j=5 组）
  - `5C5 = 1`（每个 j=5 组只有 1 个 s=5 组合）
  - **为什么是 12 组**：
    - 一个 k=6 组最多能覆盖 6 个 j=5 组合（因为从 6 个中选 5 个，只有 6 种可能）
    - 需要覆盖 56 个 j=5 组合
    - 理论最少：56 ÷ 6 ≈ 10 组
    - 但实际中，不同组覆盖的组合会重叠，且有些组合很难被覆盖
    - 通过算法验证：11 组不够，12 组可以，所以最少是 12 组

## 算法思路

这是**集合覆盖问题（Set Cover Problem）**：从所有可能的 k=6 组中，选最少的组，覆盖所有需要的 j 样本组合。

### 问题复杂度

- **NP-hard 问题**：这是经典的 NP-hard 问题，不存在多项式时间的最优解算法（除非 P = NP）
- **不可能 O(1)**：不存在能在常数时间内得到最优解的算法
- **精确解**：需要指数时间算法（回溯、分支限界、整数线性规划等）

### 当前最优算法

#### 1. 精确解算法（最优但慢）
- **回溯搜索 + 剪枝**：能找到最优解，但时间复杂度是指数级
- **分支限界（Branch and Bound）**：通过剪枝减少搜索空间
- **整数线性规划（ILP）**：用求解器（如 Gurobi、CPLEX）求解
- **适用场景**：小规模问题（如 E.g. 5 的 28 个组）

#### 2. 近似算法（快但不保证最优）

**贪心算法（Greedy）**：
- **近似比**：O(ln n) 或 H(n)（调和数），约等于 ln(n)
- **时间复杂度**：O(nm) 多项式时间
- **优点**：简单、快速
- **缺点**：可能不是最优，但理论保证不会太差

**线性规划松弛 + 随机四舍五入**：
- **近似比**：O(ln n)
- **时间复杂度**：多项式时间（求解 LP + 四舍五入）

**主对偶法（Primal-Dual）**：
- 在某些特殊结构下可能有更好的近似比

#### 3. 最新研究（2023-2025）

- **动态近似算法**：支持动态更新的 (1+ε)ln n 近似算法
- **启发式方法**：Wave Function Collapse + Hill Climbing 等新方法
- **仍为近似**：这些方法仍不能保证总是最优

### 理论下界

- **不可能常数近似**：在一般情况下，无法保证常数因子近似（除非 P = NP）
- **最优近似比**：ln n 级别的近似比几乎是理论下界
- **特殊结构例外**：在某些特殊结构（几何覆盖、频率受限等）下可能有常数近似

### 对于本项目

**实际情况**：
- 规模较小（如 E.g. 5：28 个 k=6 组，28 个 j=6 组合）
- 可以用精确算法（回溯 + 剪枝）在合理时间内得到最优解
- 不需要 O(1)，但可以在秒级或分钟级完成

**推荐方案**：
1. **小规模**（n ≤ 10）：用回溯搜索找精确最优解
2. **中等规模**（n > 10）：贪心算法快速得到近似解，或回溯 + 剪枝优化
3. **大规模**：贪心算法或启发式方法

**验证过程**：
- 通过算法验证最少组数（如 E.g. 2 的 12 组）
- 不是简单的除法，需要考虑组合覆盖的约束
- 需要程序自动计算，手动验证不现实

## 相关论文

### 经典理论结果

**Feige (1998)** - *A threshold of ln n for approximating set cover*
- 证明了一般 Set Cover 问题的近似下界
- 除非 NP ⊂ DTIME(n^polylog(n))，否则无法得到比 (1-ε)ln n 更好的近似比
- 这是理论上的最优近似下界

### 精确解算法

**Cygan, Halldórsson, Kortsarz 等 (2020)** - *Tight Bounds on Subexponential Time Approximation of Set Cover*
- arXiv: 2008.05374
- 研究次指数时间下的近似下界
- 证明即使在次指数时间下，也无法突破约 (1-γ)ln N 的近似比

### 近似算法（2023-2025）

**Solomon, Uzrad, Zhang (2024)** - *A Lossless Deamortization for Dynamic Greedy Set Cover*
- arXiv: 2407.06431
- 动态版本的贪心算法
- 近似比：(1+ε)ln n
- 最坏情况更新时间：O(f log n / ε²)

**Dhulipala, Dinitz, Łącki, Mitrović (2024)** - *Parallel Set Cover and Hypergraph Matching via Uniform Random Sampling*
- arXiv: 2408.13362
- 并行/分布式模型下的近似算法
- 近似比：O(f) 或 O(log Δ)，其中 f 是元素出现最大次数，Δ 是集合最大大小

**Dehghankar, Raychaudhury, Sintos, Asudeh (2024)** - *Fair Set Cover*
- arXiv: 2405.11639
- 考虑公平性约束的 Set Cover
- 在某些情况下保证"零不公平性"

### 优化算法

**J. Comput. Sci. (2024)** - *A succinct and approximate greedy algorithm for the Minimum Set Cover Problem*
- 优化输入数据表示，加速贪心算法
- 近似比：(1-o(n))log n
- 适合大规模集合

**Chan & He (2022)** - *More Dynamic Data Structures for Geometric Set Cover with Sublinear Update Time*
- 几何 Set Cover 的动态数据结构
- 对 2D 轴对齐正方形：O(1) 近似 + O(n^(2/3+δ)) 更新时间

**ICDCN 2025** - *Faster Set Cover in the MPC Model*
- 分布式计算模型（MPC）下的快速算法
- 使用 O(log N) 或 O(log^1.5 N) 回合完成
- 适合大规模并行场景

### 特殊结构

**arXiv (2025)** - *Covering a Few Submodular Constraints and Applications*
- arXiv: 2507.09879
- 处理多个子模函数的覆盖要求
- 在固定数量函数下有较好的近似比

## 报告表达与功能补充（新增）

### A. 报告尽量“多图讲解”的优势

建议报告用流程图、结构图、对比图、结果截图来讲，而不是只放文字。

1. **复杂逻辑更易懂**：`m,n,k,j,s,atLeast` 与覆盖关系，一张图比大段文字更直观。  
2. **证明链更完整**：可把“输入 -> 求解分支（Exact/Heuristic）-> 输出 -> Verify”画成闭环。  
3. **同时突出两大目标**：  
   - 正确性：展示 `Covered j-combinations: X/X`；  
   - 速度：展示运行时间、模式对比（fast / balanced / quality）。  
4. **评审友好**：演示时老师能快速抓到重点，减少口头解释负担。  

### B. 项目核心卖点（报告可直接用）

- **Correctness first**：小规模走 Backtracking 可给精确最优；大规模也可用 Verify 给覆盖率证据。  
- **Fast in practice**：大规模走 GRASP + 优化（预计算、剪枝、冗余移除），在可接受时间内出结果。  

### C. Verify 功能（已加入）

为支持“答案正确/错误验证”，系统新增：

- 前端：结果区新增 **Verify Candidate**，可粘贴任意候选分组 JSON（不只验证系统自己算出的结果）；
- 辅助：`Load Current` 可把当前解填入候选区，再手动改动做反例演示；
- API：新增 `POST /api/verify`（本地与 Vercel 都可用）；
- 返回：`passed`、`satisfied/total`、`coveragePct`，失败时附前几个未满足的 `jCombination`。

另外，Verify 会做结构合法性校验（每组长度必须等于 k、组内不重复、元素必须来自已选样本），避免“格式错但覆盖看似通过”的假阳性。

这让系统不仅能“算答案”，还能“独立验外部答案”，便于报告中的正确性展示与现场演示。
