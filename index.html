How to use

This tool finds the minimum number of k-groups that cover your s-subset constraints.

  • Set m, n, K, j, S and at least.
  • Choose Random n (system picks) or Input n (you type the numbers).
  • Click Calculate to run. Results appear below.
  • Use Save to history to store the result; open the History tab to view or delete saved runs.
